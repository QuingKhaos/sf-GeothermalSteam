# Geothermal Steam

Extract Super Heated Steam from Geysers for usage in Steam Turbines or Fluid Miners. This mod just adds the Geothermal Steam Extractor, which is not useful on its own, but is a required component for other mods, that consume the Super Heated Steam. By default, the Geothermal Steam Extractor is unlocked together with the Geothermal Generator.
